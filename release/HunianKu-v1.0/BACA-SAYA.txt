HunianKu - Sistem Manajemen Apartemen (v1.0)
=============================================

Isi paket:
  HunianKu.exe      -> aplikasi (tidak perlu install .NET)
  appsettings.json  -> pengaturan koneksi database (WAJIB satu folder dengan .exe)
  HunianKu.sql      -> script pembuatan database + data demo

Cara menjalankan:
  1. Pastikan SQL Server sudah terpasang (SQL Server Express gratis sudah cukup).
  2. Buka HunianKu.sql di SQL Server Management Studio, lalu klik Execute (F5).
     Atau lewat Command Prompt:
        sqlcmd -S .\SQLEXPRESS -E -C -i HunianKu.sql
  3. Buka appsettings.json dengan Notepad, sesuaikan bagian Server=
        SQL Server Express   : Server=.\\SQLEXPRESS
        SQL Server Developer : Server=localhost
        LocalDB              : Server=(localdb)\\MSSQLLocalDB
  4. Klik dua kali HunianKu.exe
     (Jika muncul Windows SmartScreen: klik "More info" lalu "Run anyway".)
